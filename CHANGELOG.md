# Changelog - PingMeDaddy (PMD)

Toutes les modifications notables de ce projet sont documentées dans ce fichier.

## [1.0.0] - 2025-01-01

### Ajouté
- Intégration Hub SSO (JWKS/JWT RS256)
- Auto-enregistrement M2M auprès du Hub
- Découverte dynamique des services partagés
- Système de backup/restore générique
- Préférences utilisateur
- Routes de test des services Hub
- Documentation et changelog API
- Monitoring réseau : ping, latency, packet loss, traceroute
- TimescaleDB pour les données de séries temporelles
- Interface web React avec graphiques en temps réel
